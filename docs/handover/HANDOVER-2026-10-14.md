## 2. What changed

### Email inquiries: a five-stage pipeline board (new default view)

`1 Inquiry → 2 Quoted → 3 Negotiation → 4 PO received → 5 Won`, Lost from any
stage. Built for **every client business**, not one: the stage *meanings* are
fixed (the mail check moves cards by them), while the *words*, optional steps,
currency and tax are set per client in **⋯ → Pipeline & wording**.

- **Board** (`addons/inquiry/board.py`): a count card per stage, tinted columns,
  cards with the customer's last line, "You ₹X vs They ₹Y" on negotiations,
  status pills (Overdue, Call them, Your turn / Their turn, Check it,
  No quotation, Looks like a PO, Proforma to send…), collapsible groups, the Won
  total, a lost line, and select mode (Delete N, Save as Excel).
- **Drawer** (`drawer.py`): slides over the board — stepper, actions for the
  stage, and Overview / Emails / Quotation / Files / Timeline tabs. No new AI
  calls; it reads what Prism stored when the mail arrived.
- **New actions** (`pipeline_actions.py`): They countered, Hold the price,
  revised quotations as **Rev 1, Rev 2…** (same number, price history kept,
  files written only after Send succeeds, never over an existing file), PO with
  no quotation → **Price it from the rate list** → acknowledgement, optional
  order acknowledgement and proforma/advance steps, Add inquiry by hand.
  **Nothing is ever sent without the owner pressing Send.**
- **Pipeline & wording** (`pipeline_setup.py`): rename stages (24-char cap),
  switch Negotiation / ask-for-details / acknowledgement / proforma on or off,
  reminder days and count, currency + tax (₹ GST, $, € VAT, AED VAT). Saving
  keeps every other setting — mailbox accounts byte-identical (proved).
- **Views**: Pipeline · Client file (the colour-graded register) · All mail.
  The old tabs remain under **⋯ → Classic tabs**.
- On narrow windows the screen collapses the sidebar to its icon rail and gives
  it back when you leave — never against the user's own choice.

### Engine (`prism_terminal/core`)

- Register: six appended columns — Revision, Price history, Their ask, Turn,
  No quotation, Proforma. **Old registers load unchanged; no status was added.**
  `stage_of()` maps every status (case-insensitive, aliases like Won/Lost) to a
  stage; 76,032 combinations checked — no row ever falls off the board.
- **Mail-check behaviour changes** (deliberate, owner-approved):
  - a reply asking for a better rate moves the inquiry to Negotiation and stores
    the customer's asking price — read only from currency-marked amounts; never
    from phone numbers, pincodes, GST/PO numbers or per-unit prices;
  - a PO moves an inquiry to PO received **only when certain** (an explicit PO
    number plus a PO-named attachment, or the mail names our quotation number).
    Otherwise the card stays put with a "Looks like a PO" pill and the owner
    confirms. "P.O. Box" addresses and signature logos no longer count.
- Rate-list pricing of a PO prices every line or lists it as unsure; revised
  totals land on the exact figure asked for.

### Lumi: an Android-style edge button

The "Need help? Ask Lumi anything." pill and walking mascot are gone. Lumi is a
~43 px round button docked to the right edge (60 % opacity at rest), with an
"Ask Lumi" label on hover, drag up/down, right-click → Tuck away / Move to
bottom, position remembered (`gui_lumi_button.json` in the user folder),
keyboard-openable. Screens no longer reserve space for it.

### Earlier in this round (already on `main` before this push)

writes (a mail check never undoes the screen), multi-delete, PDF quotations,

## 6. Traps worth knowing

- The engine's `core/config.py` reads `~/.prism` directly — any UI harness must
  set `HOME` to a sandbox, not only patch `paths`.
- From a VS Code (snap) terminal, unset the snap GTK variables and restore
  `XDG_DATA_DIRS` from `XDG_DATA_DIRS_VSCODE_SNAP_ORIG`, or Qt aborts.
- Never run the test suite while a Prism window is open (home-guard misfires).
